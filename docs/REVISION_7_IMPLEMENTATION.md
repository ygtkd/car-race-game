# 改修7・Blender全面改修 実装記録

2026-09-26。改修プロンプト7と、既存モデル・ステージをBlenderで作り直す依頼に基づく実装です。

## 実装

| 項目 | 実装箇所・内容 |
|---|---|
| マルチメニュー | `club.css`で戻るボタンと見出しを整列。`racer.js`でルーム一覧から入室、合言葉UIを廃止。車体選択はソロと同じ図鑑形式。 |
| ゴール | `RaceCore.cs`の完走後自動運転。操作と記録加算を止め、約3秒のFinish表示後に結果画面へ。推計記号を削除。 |
| 最後のプレイヤー | 人間が残る間は走行を継続。CPUのみ残った場合だけ推計。CPU・推計・DNFは実測ランキングに登録しない。完走した人間の結果はサーバーへ個別保存。 |
| CPU・グリッド | ソロとホストが難易度1～5を選択、初期値3。全員のグリッドを毎回抽選し、オンラインはサーバーから同期。 |
| スペシャル・重量 | 技名ボタン、妨害20m、通常5秒・耐性12秒。既存8車種の表示上の基礎性能は維持し、衝突時の重量差を強化。 |
| 車種 | STORM BIKEとAERO BIKEを加えた10車種。Blenderで車体を制作し、前輪・フォークの操舵と車輪回転を軽量な表示処理で実装。 |
| コース | 山岳、鈴鹿、湘南の3コースをBlenderで再制作。道路の座標は共有走行エンジンと同一。道路脇の灰色ゾーンを保持。海峡・海上橋・展望塔・海沿いの街並みを追加。 |
| 昼夜 | 3コースに昼夜を追加。全車に夜間ヘッドライトの前方照射。高コストな影付きライトは使用せず、シェーダーで処理。 |
| 地形 | 連続した地形と道路脇の斜面、コンクリート橋床・橋脚を制作。下の道路を覆う上側の斜面を除去。 |
| アイテム | 30ミッション・30種類の立体報酬。最大3点を装着。色・面・面内位置・サイズ・角度を保存。形・模様の編集UIは削除。自車の装飾が前方視界に重なる場合は該当部分を非表示。 |
| 保存・言語 | 旧報酬の取得状態と装着情報を移行。装飾の保存値を検査。日本語初期設定・英語切り替えを維持。 |
| Blenderデータ | `Art/Blender/Models`に編集用44ファイル。車体10、コース3、報酬30、コイン1。ゲーム用は専用バイナリ形式CRB7。再生成・編集後の書き出し手順は`Art/Blender/README.md`。 |

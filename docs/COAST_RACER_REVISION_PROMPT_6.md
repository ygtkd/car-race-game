# COAST RACER 改修プロンプト6

本書を新規保存し、実装・検証してmainへpushする。今回はAzure公開は作業範囲に含めない。

- 図鑑で、獲得済みバッジの取り付け面（上・左・右・前・後）と、その面の中の任意位置をドラッグまたは数値スライダーで選べるようにする。形・模様・色・サイズ・回転も編集可能にする。車種別保存、再読込、ソロ・オンライン表示に反映し、旧保存データを引き継ぐ。バッジの獲得条件は変更しない。
- スペシャルの通常時からの性能増減量を現行の5倍にする。5秒持続と発動中の演出は維持する。物理上100%が上限の効果は上限で制限し、走行不能になるものは検証結果に基づいて抑える。強化値と調整理由を記録する。ブレーキ入力で強化中も減速できることを確認する。
- 両コースと全8車種を含む10レースの自動走行テストを実施し、各レースの完走・周回・順位・特殊技・復帰回数・有限値を記録する。共通走行エンジンでの自動レースと、実ブラウザーでの操作・描画確認を区別し、実機を確認したと偽らない。
- モチーフ不明瞭な山岳コースの球形岩を、角張った不規則な形と岩肌を持つ岩へ置き換える。道路への干渉、浮き、描画負荷を確認する。車体・車輪・影・樹冠等の意図のある曲面まで一律に削除しない。
- 既存の2周、灰色減速、芝生5秒復帰、後方視点、入力保護を維持する。新規インストールは一覧化。空き容量1GiB未満では中断。既存CarController.csのユーザー変更は触れずコミットしない。
- プロンプト・検証結果・WebGL公開用成果物を保存し、pushまで行う。

# COAST RACER 改修プロンプト5

既存のプロンプトを上書きせず、本書の改修を実装・検証し、mainへpushしたうえでGitHub ActionsからAzureへ公開する。

- ゴールの市松模様と、ゴール地点を示す頭上の市松模様のテープを両コースに設ける。描画位置と判定位置を一致させ、装飾の道路重なり除外から明示的に区別する。
- 周回判定を再点検する。中間地点の点への接近だけでなく、順路上の通過も検出する。道路と灰色路肩を走行してゴールを前向きに越えれば周回を記録する。芝生でのゴール、逆走、別の高さ、大幅なショートカット、復帰だけでの進行は認めない。2周完走をソロ・オンラインで検証する。
- 地形の裏面消失と、立体交差で上側地面を切り抜いた箇所から背景が透ける問題を確認する。両面の路面と最下層の地面を設け、上側の地形で下側道路を覆わない。
- すべてのスペシャルは5秒。通常性能に対する増減量を2倍とする（加速倍率1.35→1.70、最高速1.12→1.24、グリップ1.30→1.60等）。妨害範囲12→24m、瞬間減速18→36%、継続減速2→4、妨害持続も5秒。シールドの接触重量増加80→160%。既に完全無効化する効果は完全無効化を維持する。芝生減速50%軽減→100%軽減。発動者・被妨害者の効果を持続時間中途切れず描画し、終了時に消す。車種説明の時間も更新する。
- 全車の名前背景と枠線を削除し、名前文字と読みやすい影を残す。
- アクセルの上に小さい後方視点ボタンを追加する。タップで三人称の後方を見るカメラへ切り替え、再タップで通常視点へ戻す。自分の車も映す。アクセル・ハンドルと同時に使えること。停止・画面遷移・フォーカス喪失時は通常視点へ戻す。日本語・英語に対応する。

既存の2周・灰色減速・芝生5秒復帰・入力保護を維持する。Azure無料枠のみ使用し、新規インストールがあれば一覧化する。空き容量1GiB未満で作業を中断する。ユーザー既存のCarController.csは変更・コミットしない。検証・未確認事項・公開ビルドIDを別の実装記録へ保存し、実機未検証を明示する。

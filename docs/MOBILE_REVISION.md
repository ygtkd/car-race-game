# モバイル改修（2026-09-23）

## 仕様
- 全コース2周。オンライン結果はridge-2lap/suzuka-2lapとして保存・参照し旧3周記録を混在させない。
- 端末プロファイルversion4で旧履歴・ベスト・集計をリセット。名前、音量、入手済みバッジ、装飾は保持。
- 旧SQL行の削除はRemove-Legacy-Three-Lap-Records.sqlをDB管理者が実行可能。今回のpushでは実DBを変更しない。
- コース中心から14m超の横方向逸脱が3秒続くと最後の通過ゲートへ自動復帰。範囲内へ戻ると解除。既存3秒ペナルティと進行保護を維持し、復帰後2秒間は車体接触を無効化。
- 手動復帰ボタン・Rキー・WebSocketのrecover操作を廃止。
- 芝生の警告は「コースに戻ってください」。メーター直径は通常71px、低い画面59px。
- ハンドル判定は長方形で幅2倍。入力欄以外の文字選択・長押しメニューを抑止。操作ボタンはtouch-action:manipulation。
- スタート信号・開始ブザー・アクセルと速度に連動する合成エンジン音。156BPMのオリジナルレースBGM。自転車は低音量の走行音。
- ケバブ屋、バナナボート、トゥクトゥク、自転車を追加。図鑑と装飾、ステータス、衝突・オンライン同期に対応。
- 山岳の岩・木立、鈴鹿サーキットの観客席・照明を追加。既存のマテリアル単位メッシュ結合で描画負荷を抑える。
- オリジナル図形のPNGホーム画面アイコンとWeb App Manifest。COAST RACERの表示名を統一。
- ヘッダー余白は再現確認のみ。不要な余白補正は追加していない。

# コースの設計と参照資料

## 山岳サーキット

オリジナル設計。20点の制御点をCatmull–Rom曲線で補間し、640点で路面を構成しています。全長は約1,696m。路面中央の標高差は約30mです。実在する場所の再現ではありません。

## 鈴鹿風サーキット（非公式）

参考にした一次資料:
- 鈴鹿公式コースガイド: https://www.suzukacircuit.jp/eng/course_s/
- 公式コース図: https://www.suzukacircuit.jp/eng/course_s/img/seat-map.jpg
- 公式ガイドPDF: https://www.suzukacircuit.jp/course_s/pdf/suzuka_courseguide.pdf

公式図を目視で確認し、手作業で制御点を作成しました。公式画像をゲームのテクスチャや配布アセットには使用していません。

反映した特徴:
- ホームストレートと最初の右コーナー
- S字状の連続コーナー
- デグナー方向からヘアピンへ向かう流れ
- スプーン方向の大きな折り返し
- バックストレートと立体交差
- 終盤のシケインからホームストレートへ戻る構成

簡略化:
- 公式コースの四輪用全長5.807kmに対し、ゲーム内は約3.358kmへ短縮しています。
- コーナー半径、幅員、高低差、バンクは実測値ではありません。幅員は一律14mとしています。
- 標高は制御点に手作業で設定しました。立体交差で走行層を取り違えないよう、直前の進行位置付近を投影対象にします。
- 建物、看板、樹木、ピットは一般化した独自の手続き生成モデルです。実際の施設やロゴを再現していません。
- 640点の補間形状を採用しており、公式の正確なトレーニング用途には適しません。

道路のレイアウトデータは Assets/Scripts/Core/RaceCore.cs にあり、Unityと対戦サーバーが同じものを使用します。

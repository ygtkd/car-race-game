# COAST RACER 改修プロンプト4

## 対象と作業範囲
最新の公開版とコードを調べ、以下を実装・検証し、GitHubへpushしてGitHub ActionsでAzureに公開してください。過去プロンプトは上書きせず残してください。本書で変更しない既存仕様（2周、灰色ゾーンの減速と警告なし、芝生だけの5秒復帰、右上設定、特殊技等）を維持してください。

## R4-1 鈴鹿の地形・立体交差
- 上下に道が重なる場所で道路が消える、地形が道路を覆う、観客席が道に重なる不具合を修正する。
- 道路、路肩、灰色ゾーン、芝生、橋の下面・支柱、観客席・照明・ガードレールを個別に確認する。上側の地形が下側道路に貫通する描画をなくす。
- 上下両方の走行経路を確保し、他の道路区間の上に施設を置かない。単に交差を平面化したりコースを消したりして解決しない。
- 立体交差の上・下・進入・退出の実走行画像を残す。山岳コースも回帰確認する。

## R4-2 鈴鹿の周回・完走
- 2周目のゴールラインを通過しても終了しない報告を最優先で再現・調査する。チェックポイント取りこぼし、路肩走行、復帰、高低差・近接する別区間への誤認、低速・高速通過を確認する。
- 正しい順路を走行してゴールラインを前向きに越えたとき、1周目は2周目へ、2周目は完走として1回だけ記録する。ライン手前や逆走、別の高さの道路、コースの大幅な飛ばしで完走させない。
- 灰色ゾーンを走っただけでチェックポイントが永久に未通過となり、以後ゴールできなくなる状態をなくす。復帰による進行・順位・タイムの不正な加算を防ぐ。
- 共通ロジックのテストに加え、ブラウザー内で鈴鹿を実際に2周走り、結果表示・記録まで確認する。ソロとオンラインの共通判定を照合し、オンラインでも確認する。

## R4-3 アクセル残留・操舵不能
- 押していないのにアクセル入力が残る、ハンドルが突然効かなくなる問題を調査し修正する。入力値、車速、勾配による惰性を分けて記録する。
- 複数指、細かい連打、左右切替、指がボタン外に出る、指を離す、pointercancel、キャプチャ喪失、画面回転、停止・設定・ダイアログ開閉、バックグラウンド復帰を確認する。
- 古いポインターIDが残って新しい操舵を拒否したり、離した指のアクセルを再送し続けたりしないようにする。タッチ終了を独立した経路でも確認する。
- 入力送信が停止した場合はUnityとオンラインサーバー側で安全に中立へ戻す。正常な長押しは継続できるようにする。
- 設定や停止から戻った直後も新しいタッチに反応し、ペダルと操舵を同時に操作できることを確認する。

## R4-4 メーターの数字
- 円形メーター内の速度・ギアの数字の文字サイズを、現行の70％にする。メーターの直径、数字以外の単位、他のHUDのサイズは変更しない。
- 通常画面と高さの小さいスマホ画面の両方で、計算済みフォントサイズが元の0.7倍になることを確認する。

## 完了条件・制約
- 要件別に原因、変更、検証結果、証拠、未確認事項を新しい実装台帳へ記録する。実機がない場合は実機合格と報告しない。
- WebGLとWeb資産を同じビルドIDでパッケージ化。push後のActions成功に加え、公開URLのビルドID・ロード・レース開始を確認する。

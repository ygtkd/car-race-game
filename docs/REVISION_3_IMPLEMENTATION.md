## 実装
| 要件 | 原因・変更 | 検証 |
| --- | --- | --- |
| R3-1 灰色ゾーン | e9ce93eではRunoffは灰色、後のコードではgrass素材。元の色(.34,.36,.33)と中心から±16mの幅を復元。縁石外端8.1mから16mまで減速、16m超だけ5秒警告。減速抵抗2.5+速度×0.22 m/s²。灰色に戻ると警告解除。復帰先は道路・縁石走行時のみ保存 | 両コース共通ロジック: 灰色6秒で復帰なし、全開40m/sから減速、芝生→灰色解除、道路中心の保存、5秒復帰に合格 |
| R3-2 停止後の操作 | UnityとHTML双方のフォーカス一時停止をWebではHTML側に一本化。再開時に画面遷移を完了してからUnityを再開 | 実機報告の原因と断定しない。ブラウザー反復確認を行う |
| R3-3 連打 | windowのcaptureフェーズでもup/cancelを受け取る。操舵入力は指離し時に即中立。キャプチャ解除前に状態をクリア。設定・遷移・確認ダイアログ中の新規入力を抑止 | 連打とペダル同時操作、停止復帰、判定外での指離しを確認する |
| R3-4 特殊技 | 車両ごとの固定数LineRendererプールで、サーバー／共通走行状態に連動した効果を描画。満タンの縁取り、発動中の色・技名・残秒を追加。性能・持続時間・SE設定は維持 | 特殊技の画像検証はスナップショットfixtureを使い、実走行での発動検証と区別する |
| R3-5 木 | 先細りの幹と枝、不規則な低ポリゴン樹冠、段状の針葉樹。固定シードで大きさ・形・葉色を変化。車道周囲には配置しない。素材ごとの結合で描画呼び出しを抑制 | コードによる自作。外部素材・新規インストールなし。画像・負荷を確認する |

灰色ゾーンの外に芝生を確保するため、旧16mの障壁判定は25mへ、ガードレールは25.5mへ移動。道路形状・勾配・周回数は変更しない。これは灰色全域から芝生へ進入可能にし、復帰カウントを成立させるための付随変更。

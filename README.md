# COAST RACER — スマホWeb版

Unity 6000.6.2f1で動く、アシスト付きドライビングゲームです。ブラウザで遊ぶ構成で、Azure App Serviceに対応しています。

## このPCで遊ぶ

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./Deployment/Preview-Web.ps1
```

表示された **http://localhost:5080/play/** を開いてください。サーバーを止めるにはPowerShellでCtrl+Cを押します。同じPCで複数のブラウザを開くと2人対戦を試せます。localhostはスマホから直接アクセスするための公開URLではありません。

## 操作

- スマホ: 横画面。ハンドルの左半分を押すと左、右半分を押すと右へ曲がり、右のアクセル／ブレーキを押します。同時押しに対応しています。
- PC: W／上でアクセル、S／下／Spaceでブレーキ、A・D／左右で操舵、Eでスペシャル。
- 指を離すとハンドルは中央へ戻ります。変速は自動です。
- 芝生で5秒のカウントダウンが終了すると、逸脱直前の道路の中心へ自動復帰し、3秒加算されます。範囲内に戻るとカウントダウンを解除します。
- ゲーム設定で名前、感度、アシスト、描画品質、言語、BGM音量・効果音音量・ミュートを変更できます。初回は日本語です。
- オンライン中は一時停止できません。タブを離れると入力を解除し、サーバーが減速させます。

設定は暗いダイアログで開き、右上の×、ダイアログ外の背景、Escで閉じます。言語も設定内で変更できます。ソロ走行中は設定を開くと一時停止し、オンライン中はレースが継続します。

メニューでプレイモード、8種類の車体、コースを順に選び、短いローディング後にスタートします。開始するまでは3Dコースを表示しません。

## モードとコース

**シングルプレイ**: ライバル3台と2周。ベストタイムをコース別にブラウザへ保存します。

**オンライン対戦**: ゲーム設定の名前でルームを作成し、コードを友人へ共有します。参加可能な部屋は一覧からも選べます。ホストがコースとCPU台数を指定し、各自が車体を決定すると自動開始します。人間とCPUの合計は最大8台、初期設定はサーバー全体で8接続です。車同士は接触し、コインとスペシャルも共有されます。全員の読み込み完了後に共通カウントダウンで開始します。終了後「再戦の準備へ」から再戦できます。

- 山岳サーキット: 約1.70km。直線、左右コーナー、連続コーナー、上り下り。
- 鈴鹿サーキット: 約3.36km。S字、ヘアピン、立体交差を含む簡略化コース。実コースの縮尺や標高を忠実に再現したものではありません。参考資料と省略箇所は [コース資料](docs/COURSES.md) に記載しています。

図鑑で車体を360度眺め、獲得バッジを装着できます。記録画面には完走、勝利、コイン、スペシャル、車種・コース別記録を保存します。詳しい性能と検証条件は [Club拡張仕様](docs/CLUB_EXPANSION.md) を参照してください。

## 実装範囲

入力、車両シミュレーション、コース・周回判定、Unity描画、ブラウザUI、対戦サーバーを分離しています。
車両は速度依存のステアリング、グリップ制限、横方向の追従、勾配による加減速、路肩・壁での減速を備えた簡略モデルです。商用シミュレーターと同等のサスペンションやタイヤモデルではありません。

ネットワークはブラウザ対応の標準WebSocketを使用します。位置・周回・順位・結果はサーバーが計算し、クライアントが申告する座標やタイムを採用しません。クライアント側でも入力を予測し、サーバーの状態で補正します。

日本語フォントはブラウザのシステムフォントを使い、Unityのフォントアセットによる日本語グリフ不足を避けています。Unityエディター内では開発用の簡易操作画面を表示します。完成UIはWeb版で確認してください。

## 開発・ビルド

Unity Hubでこのフォルダーを開き、メニューの **Coast Racer → Build Web Game** を実行します。出力は `Builds/site` です。
検証用コピーを使う場合は `Deployment/Build-Guarded.ps1` で空き容量を監視したビルドも可能です。残り1GiB未満で停止し、進捗と `Logs/capacity-stop.flag` を記録します。停止後は容量を確認し、再開指示を得てから対応してください。

メモリが少ないPCでは、ブラウザ検証や他のビルドを同時に動かさずに実行してください。

```powershell
dotnet restore Server/CoastRacer.Server.csproj --packages .packages --locked-mode
dotnet build Server/CoastRacer.Server.csproj --no-restore
dotnet run --project Tests/CoreTests.csproj
```

主要ファイル:

| 場所 | 内容 |
|---|---|
| Assets/Scripts/Core/RaceCore.cs | Unityとサーバーで共有するコース・車両・チェックポイント |
| Assets/Scripts/CoastRacer.cs | Unityの路面・景観・車体描画と状態同期 |
| Assets/WebGLTemplates/CoastRacer | 日本語・英語UI、仮想ハンドル、WebSocketクライアント |
| Server | App Serviceで動く配信・対戦・結果保存サーバー |
| Tests | 走行判定と2接続でのオンライン完走テスト |
| Deployment | プレビュー、梱包、無料設定検査、Azure構成定義 |

追加した依存関係とツールは [INSTALLATIONS.md](INSTALLATIONS.md) に記録しています。改修前のバックアップは `Backups/BeforeProRacer-*.zip`、今回の拡張前は `Backups/Before-Club-Expansion-*.zip` です。

## Azure

使用するのは **App Service Free（F1）とAzure SQL Database無料オファーのみ**です。旧Azure Storage公開方式は使いません。

このPCでは開発モードとして結果を `Server/App_Data/results.json` に保存します。本番モードはAzure SQL接続が必須で、未設定なら起動時にエラーになります。ローカルJSON保存はAzure SQLの実接続確認の代わりにはなりません。

[Azure公開手順](Deployment/AZURE.md) を参照してください。リソースの作成・公開・課金設定の変更は今回実行していません。

## 検証と制限

最新の結果は [検証記録](docs/VALIDATION.md) にまとめています。
PCブラウザでのスマホ模擬入力と、実際のiPhone・Androidによる確認は別です。実機性能、インターネット経由の対戦、Azure SQL実接続は未検証です。

ルームはサーバーのメモリ上にあります。サーバー再起動時にはルームを失い、利用者へ再参加を案内します。再接続期限は20秒で、期限後は未完走になります。最初の完走者から90秒後、またはレース開始から15分で残りの車を未完走として終了します。

Freeプランは試作・少人数検証向けです。常時稼働、多数同時接続、モバイルでの一定fpsは保証していません。4人設定はコード上の上限として用意していますが、初期設定と検証対象は2人です。
